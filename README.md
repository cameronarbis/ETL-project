--- Learning ETL ---		
This project's current pipeline: 

- [x] **Stage 1 — Data Generator** · Python + Faker on RPI, emits JSON transactions
- [x] **Stage 2 — Infrastructure** · Docker: Kafka, Zookeeper, Postgres, Kafka UI, pgAdmin
- [x] **Stage 3 — Ingress API** · Spring Boot REST service (`:8081`) → Kafka topic `transactions`
- [ ] **Stage 4 — ETL Pipeline** · Kafka consumer → transform → Postgres load

My target data is being generated by a raspberry pi on my local network. I am ingressing that data, transforming it and loading into a different database for further processing. 

Stage summaries:

Stage 1. Data Generator (data-generator/)
Python script using Faker that produces realistic financial transaction JSON. Runs continuously or for a fixed count.
Currently configured to POST to http://localhost:8080/api/transactions and also write to transactions.jsonl.
